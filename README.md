# Processo de criação do prompt
- Persona: Time de produtos, avaliação de uso dos produtos (usabilidade)

Quero que a IA analise base de comentários para identificar as principais produtos utilizados e suas dificuldades.

O resultado será usado por time de produto para apoiar na melhoria e usabilidade dos aplicativos.

A entrega deve conter uma lista de insights com os produtos mais e menos utilizados.

O resultado será considerado bom se focar em ações para os possíveis ajustes baseando-se nesses comentários, identificando gaps de usabilidade.

Contexto: Estou trabalhando com feedbacks de clientes bancários relacionados ao uso do aplicativo, especificamente no produto cambio.

Dados disponíveis: A base contém nome de usuário, e-mail, texto descritivos de experiência de uso, notas atribuídas à experiência.

Critérios de análise: A IA deve classificar os feedbacks por uso do produto cambio, caracterização de uso, canal de contato.

Cuidados e restrições:

Use apenas os dados fornecidos.
Não invente números, causas ou conclusões.
Não exponha dados pessoais ou sensíveis.
Se houver informação insuficiente, indique a limitação.
Use linguagem técnica e explore conceitos de UX.

### Prompt final ###
Atue como analista de dados e experiência do cliente em um banco.

Sua tarefa é analisar a base de comentários sobre o uso do produto de cambio no aplicativo do banco para apoiar na melhoria dos aplicativos.

Contexto: Estou trabalhando com feedbacks de clientes bancários relacionados ao uso do aplicativo, especificamente no produto cambio. Os clientes reclamam ou opinam sobre o uso do produto e precisamos identificar os pontos que precisam ser alterados para melhorar a fluidez de navegação e usabilidade.

Dados disponíveis: A base contém nome de usuário, e-mail, texto descritivos de experiência de uso, notas atribuídas à experiência.

Instruções de análise:
Classifique os feedbacks por uso do produto de cambio.
Identifique os principais padrões, problemas, elogios e oportunidades.
Aponte evidências nos dados fornecidos.
Sugira ações práticas para o time de desenvolvimento do produto.

Formato da resposta: Elenque em tópicos as melhorias que necessitam atenção da mais importante para a menos. Indique o que deve ser melhorado e porque.

Restrições:
Use apenas os dados fornecidos.
Não invente números, causas ou conclusões.
Não exponha dados pessoais ou sensíveis.
Informe limitações quando os dados não forem suficientes.
Use linguagem linguagem técnica de UX e desenvolvedores frontend e backend.
